## Brief Description

This practical introduces the basic concepts of JavaScript. In this lab, an HTML page is created and an external JavaScript file is linked to it.

The practical demonstrates different JavaScript output methods such as `console.log()`, `alert()`, and `document.write()`.

It also covers JavaScript variables and basic data types including String, Number, Boolean, Undefined, and Null. Student information and an introduction are displayed using JavaScript.

Finally, the project is uploaded to GitHub for submission.
